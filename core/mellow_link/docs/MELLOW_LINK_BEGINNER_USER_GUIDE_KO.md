# 멜로우 링크 판맥 사용 설명서

이 문서는 컴퓨터를 거의 처음 쓰는 사람도 따라할 수 있게,
화면에 보이는 문구를 기준으로 순서대로 설명한다.

멜로우 링크 판맥(MellowLink Senseframe)은 레거시 시스템의 구조, 흐름, 판단 근거를 분석하고 실행 가능한 현대화 방향으로 정리하는 웹 기반 판단 지원 프로그램입니다.

이 프로그램은 대표 분석 시나리오인 `레거시 현대화 분석` 기능에서 파일을 올리고,
무엇을 유지하고 무엇을 바꿔야 하는지 결과를 받는다.

중요:

- 이 문서는 `사용 방법` 설명서다.
- 서버 설치와 개발 환경 구성은 다루지 않는다.
- 이 문서를 쓰는 사람은 이미 프로그램이 켜져 있다고 가정한다.

## 0. 시작 전에 준비할 것

먼저 아래 3가지만 준비한다.

1. 인터넷 브라우저
   - 예: Chrome, Edge
2. 분석할 파일
   - 예: `.java`, `.jsp`, `.sql`, 화면 설명 문서, 업무 설명 문서
3. 로그인 정보
   - 아이디와 비밀번호

## 1. 화면 열기

1. 브라우저를 연다.
2. 맨 위 긴 칸을 한 번 클릭한다.
   - 보통 웹사이트 주소가 들어가는 칸이다.
3. 아래 주소를 그대로 입력한다.

```text
http://127.0.0.1:8000/projects/create
```

4. 키보드에서 `Enter` 키를 누른다.

정상이라면 화면 위쪽에 아래 문구가 보인다.

- `멜로우 링크 판맥`
- `MellowLink Senseframe`
- `새 프로젝트`
- `내 프로젝트`
- `결과 보기`

## 2. 로그인하기

화면 안에서 아래 영역을 찾는다.

- `인증 상태`
- `Username`
- `Password`
- `로그인`

따라할 순서:

1. `Username` 칸을 클릭한다.
2. 받은 아이디를 입력한다.
3. `Password` 칸을 클릭한다.
4. 받은 비밀번호를 입력한다.
5. `로그인` 버튼을 누른다.

정상이라면 아래처럼 바뀐다.

- `로그인됨: ...`
- `로그아웃` 버튼이 보임

만약 아래 문구가 보이면 아직 로그인 전이다.

- `로그인이 필요합니다. 프로젝트 생성과 결과 조회는 로그인 후 사용합니다.`

이 경우 아이디나 비밀번호를 다시 확인한다.

## 3. 새 분석 만들기

로그인 후, 가운데 큰 입력 영역을 채운다.

화면에서 아래 항목을 순서대로 찾는다.

- `프로젝트명`
- `고객사명`
- `고객이 원하는 방향`
- `자산 업로드`
- `제약 조건`
- `고급 옵션`
- `분석 시작`

### 3-1. 프로젝트명 입력

`프로젝트명` 칸을 클릭하고,
이번에 분석할 내용을 짧게 적는다.

예:

- `주문관리 화면 현대화`
- `정산 화면 개선 검토`
- `회원 조회 기능 구조 분석`

쉽게 말해, `이 분석의 제목`이라고 생각하면 된다.

### 3-2. 고객사명 입력

`고객사명` 칸을 클릭하고 회사 이름을 적는다.

예:

- `OO생명`
- `OO유통`
- `사내 테스트`

연습용이면 `사내 테스트`처럼 적어도 된다.

### 3-3. 고객이 원하는 방향 입력

`고객이 원하는 방향` 칸은
“어떻게 바꾸고 싶은가”를 적는 곳이다.

한 줄에 하나씩 적으면 편하다.

예:

- 화면은 최대한 유지하고 싶다
- 백엔드부터 먼저 분리하고 싶다
- 한 번에 전체 교체는 피하고 싶다
- React + REST 방식이 좋다

어렵게 쓸 필요 없다.
평소 말하듯 적으면 된다.

## 4. 파일 올리기

이제 `자산 업로드` 영역으로 내려간다.

여기서 보이는 문구:

- `자산 업로드`
- `파일 묶음 업로드`
- `업로드`
- `아직 업로드한 파일이 없습니다.`

따라할 순서:

1. `파일 선택` 버튼을 누른다.
   - PC에 따라 버튼 이름이 조금 다를 수 있다.
   - 예: `파일 선택`, `찾아보기`, `Choose Files`
2. 분석할 파일이 들어 있는 폴더를 연다.
3. 필요한 파일을 선택한다.
4. `열기`를 누른다.
5. 다시 화면으로 돌아오면 `업로드` 버튼을 누른다.

정상이라면:

- 업로드 상태 문구가 바뀐다.
- 아래쪽에 파일 목록이 보인다.

### 어떤 파일을 올리면 되나

정답은 간단하다.

`이 기능을 이해하는 데 도움이 되는 파일`을 올리면 된다.

예:

- 화면 파일
- Java 소스
- JSP
- SQL
- 테이블 설명 문서
- 업무 설명 문서
- 메모 텍스트 파일

### 처음 쓰는 사람용 쉬운 기준

모르면 이렇게 생각하면 된다.

- “이 기능을 다른 사람에게 설명할 때 보여줄 자료”를 올린다.

## 5. 제약 조건 입력

다음으로 `제약 조건` 칸이 보이면,
지켜야 할 조건을 적는다.

이 칸은 선택 사항이지만,
알고 있으면 적는 편이 좋다.

예:

- DB 구조는 지금 바로 못 바꾼다
- 화면 모양은 크게 바꾸면 안 된다
- 1차 오픈 전까진 기능 추가를 최소화해야 한다
- 단계적으로 나눠서 바꾸고 싶다

이 칸도 한 줄에 하나씩 적으면 보기 쉽다.

## 6. 고급 옵션은 언제 쓰나

`고급 옵션`을 눌러 펼치면
`설계 기준 템플릿`이 보인다.

보통은 그대로 두면 된다.

화면에 아래 선택지가 보일 수 있다.

- `자동 추천 템플릿`
- `Layered Enterprise`
- `React + REST`

처음 쓰는 사람은 아래처럼 생각하면 된다.

- 잘 모르겠다: `자동 추천 템플릿`
- 웹 프론트/백엔드 분리 느낌을 원한다: `React + REST`
- 전통적인 계층 구조를 원한다: `Layered Enterprise`

잘 모르겠으면 `자동 추천 템플릿` 그대로 둔다.

## 7. 분석 시작하기

이제 아래 버튼을 찾는다.

- `분석 시작`

누르기 전에 마지막으로 확인할 것:

1. `프로젝트명`이 들어갔는지
2. `고객사명`이 들어갔는지
3. 파일이 1개 이상 업로드됐는지

확인 후:

1. `분석 시작` 버튼을 누른다.
2. 잠시 기다린다.

정상이라면 자동으로 다음 화면으로 이동한다.

- 프로젝트 상세 화면
- 또는 워크스페이스 화면

## 8. 분석 중일 때 보기

분석을 시작한 뒤에는 상태가 아래처럼 보일 수 있다.

- `실행 중`
- `대기 / 시작 안 됨`
- `완료된 결과`
- `실패`

처음에는 이렇게 이해하면 충분하다.

- `실행 중`: 지금 분석하고 있음
- `대기 / 시작 안 됨`: 아직 시작 전이거나 기다리는 중
- `완료된 결과`: 결과를 볼 수 있음
- `실패`: 다시 확인 필요

## 9. 결과 보기

분석이 끝나면 결과 화면으로 이동한다.

이 화면에서 자주 보게 되는 문구:

- `결과 패키지`
- `내부`
- `외부`
- `워크스페이스`
- `한 줄 결론`
- `고객이 원하는 방향`
- `구조 비교`
- `설계 선택지`
- `실행 계획`
- `리스크`

### 무엇부터 보면 되나

처음 쓰는 사람은 아래 순서로 보면 된다.

1. `한 줄 결론`
   - 가장 중요한 요약
2. `고객이 원하는 방향`
   - 내가 입력한 요구가 반영됐는지 확인
3. `구조 비교`
   - 지금 구조와 추천 구조 차이 확인
4. `실행 계획`
   - 무엇부터 해야 하는지 확인
5. `리스크`
   - 조심해야 할 점 확인

## 10. 내부 / 외부 차이

결과 화면 위쪽에 `내부`, `외부` 버튼이 있다.

쉽게 기억하면 된다.

- `내부`: 자세히 보는 버전
- `외부`: 공유하기 쉽게 정리한 버전

처음에는 이렇게 쓰면 된다.

- 내가 검토할 때: `내부`
- 고객이나 비개발자에게 보여줄 때: `외부`

## 11. 결과 저장하기

결과 화면에서 아래 버튼들이 보일 수 있다.

- `검토용 마크다운`
- `검토용 DOCX`
- `검토용 PPTX`
- `검토 PDF 저장`

아주 쉽게 말하면:

- 문서로 넘기고 싶다: `DOCX`
- 발표 자료처럼 보고 싶다: `PPTX`
- 화면 그대로 저장하고 싶다: `PDF`

PDF 저장은 보통 이렇게 한다.

1. `검토 PDF 저장` 버튼을 누른다.
2. 저장 화면이 뜨면 `PDF로 저장`을 선택한다.
3. 저장 위치를 고른다.
4. `저장`을 누른다.

## 12. 내 프로젝트 다시 보기

나중에 다시 보고 싶으면,
처음 화면 또는 상단 메뉴에서 아래를 누른다.

- `내 프로젝트`

여기에서 예전에 만든 프로젝트 목록을 보고
다시 들어갈 수 있다.

프로젝트 카드에서 보통 아래 링크를 본다.

- `워크스페이스`
- `결과 보기`

## 13. 자주 하는 실수

### 실수 1. 로그인 안 하고 시작함

증상:

- `먼저 로그인하세요.`
- 프로젝트 목록이 안 보임

해결:

- 위쪽 로그인 영역에서 먼저 로그인

### 실수 2. 파일을 선택만 하고 업로드를 안 함

증상:

- 파일을 골랐는데 분석 시작이 안 됨
- 업로드된 목록이 안 보임

해결:

1. 파일 선택
2. `업로드` 버튼까지 눌러야 함

### 실수 3. 프로젝트명이나 고객사명을 비워 둠

증상:

- 시작 버튼을 눌러도 진행 안 됨

해결:

- `프로젝트명`
- `고객사명`

두 칸을 모두 채움

### 실수 4. 결과가 안 뜬다고 바로 꺼 버림

해결:

- `실행 중`인지 먼저 확인
- 조금 기다린 뒤 새로고침
