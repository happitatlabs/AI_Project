# Docs Backup

`_backup/`은 활성 문서에서 분리한 보관 영역이다. 여기 있는 파일은 삭제 대신 보관한 것이며, 현재 개발 기준의 기본 참조 경로는 아니다.

## 폴더 규칙

- `legacy_ai_bundle/`
  - 과거 `docs/AI/` 복사본 정리 결과
  - 활성 문서와 중복되거나, AI 참조 묶음 용도로만 쓰였던 파일 보관

## 사용 원칙

- 새 작업은 먼저 루트 `docs/`를 본다.
- `_backup/`은 과거 문맥 확인이나 복구가 필요할 때만 본다.
- 백업 문서를 다시 활성 문서로 승격할 때는 루트 `docs/`로 옮기고 참조 경로를 함께 갱신한다.
