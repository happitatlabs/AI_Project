# 파일럿 데모 샘플 선정

## 샘플 A: 레거시 코드+SQL 현대화 분석

권장 경로:

- `01. java_order_closure_case_01`

데모 목적:

- Java/JSP/SQL 자료에서 현행 구조, 핵심 문제, 개선 선택지, 실행 준비 계획이 나오는지 보여준다.

검토 기준:

- 구조 문제와 권장안이 코드/SQL 근거에 연결된다.
- 실행 준비 계획이 자동 코드 치환처럼 보이지 않는다.
- DOCX 보고서에 입력 자산 목록과 run_id가 남는다.

## 샘플 B: 컨설팅 PPT 기반 업무/현대화 검토

권장 경로:

- `08_consulting_output_reference/assets`

데모 목적:

- PPT 기반 업무/컨설팅 문서에서도 보고서형 결과를 만들 수 있음을 보여준다.

검토 기준:

- 입력 PPT 도메인과 맞지 않는 원가/회계 질문이 섞이지 않는다.
- 일반 컨설팅 문서는 현행 구조, 업무 흐름, 개선 방향, 판단 기준 중심으로 질문을 만든다.
- DOCX 보고서가 고객 공유용 초안으로 읽힌다.

## 공통 데모 흐름

`새 프로젝트 -> 업로드 -> 분석 -> DOCX 다운로드 -> 보고서 설명`

목표 시간은 10분 이내다.
