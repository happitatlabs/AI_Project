# 샘플 B: 업무 접수/처리 프로세스 개선 검토 자료

## 샘플 목적

이 샘플은 컨설팅형 업무 개선 자료를 업로드했을 때 MellowLink 판맥이 슬라이드 흐름을 읽고 문제, 개선 방향, 보완 포인트, 실행 준비 계획을 DOCX 판단 보고서 형태로 재구성할 수 있는지 확인하기 위한 데모 입력 팩이다.

## 포함 파일 목록

- `slides.md`: 12장 분량의 슬라이드 대체 Markdown 원본
- `sample_b_consulting_ppt_review.pptx`: 동일 내용을 담은 PPTX 데모 입력 파일
- `expected_report_outline.md`: 분석 결과와 비교할 기대 보고서 개요
- `README.md`: 샘플 목적과 데모 사용 가이드

## 검증하려는 기능

- 표지에서 실행 계획까지 이어지는 컨설팅 자료 흐름을 인식하는지 확인한다.
- 현재 업무 흐름, 사용자/운영 관점 이슈, 데이터/연계 관점 이슈를 구분해 추출하는지 확인한다.
- 선택지 비교와 권장안을 보고서형 판단 구조로 재구성하는지 확인한다.
- 특정 전문 영역의 표현이 섞이지 않고 일반 업무/시스템 현대화 관점으로 유지되는지 확인한다.

## 기대되는 DOCX 보고서 특징

- 현재 업무가 메일, 엑셀, 게시판, 담당자 개인 관리로 분산되어 있다는 구조가 요약되어야 한다.
- 접수, 검토, 처리, 완료, 반려 상태 기준이 모호하다는 문제가 핵심으로 잡혀야 한다.
- 개선 선택지는 채널 정리 중심, 프로세스 표준화 중심, 통합 접수/처리 포털 중심으로 비교되어야 한다.
- 권장안은 상태 기준 표준화와 처리 이력 관리 기반을 먼저 만들고 통합 포털로 확장하는 단계안이어야 한다.
- 리스크와 실행 준비 계획은 조직별 처리 기준 차이, 데이터 정리, 기존 도구와의 연계 범위를 포함해야 한다.

## 데모에서 설명할 포인트

- `slides.md`는 슬라이드 제목, 핵심 메시지, 본문 bullet을 일관되게 제공한다.
- PPTX 파일은 실제 업로드 입력으로 사용할 수 있는 대체 자료다.
- 기대 보고서 개요는 자동 생성 DOCX의 논리 전개와 비교하기 위한 기준이다.

## 주의할 점

- 모든 조직명, 요청 유형, 수치는 데모용 가상 정보다.
- 이 샘플은 일반 업무/시스템 현대화 검토 자료이며 특정 고객사나 특정 산업의 실제 자료가 아니다.
- 분석 목적은 컨설팅 자료 재구성과 판단 보고서 초안 생성 검증이다.
