멜로우 링크 판맥 분석 워크스페이스 가이드

멜로우 링크 판맥은 입력 자료가 어떤 판단을 요구하는지, 무엇을 근거로 봐야 하는지, 어디가 부족한지, 어떤 선택지가 있는지, 실행해도 되는지를 정리하는 웹 기반 판단 지원 프로그램입니다. 분석 워크스페이스는 그 판단 구조를 검토하고 보완하는 작업 공간입니다.

분석 품질은 입력 자료의 목적, 범위, 근거 수준에 영향을 받습니다. 자료가 많더라도 목적과 판단 질문이 불명확하면 결과 신뢰도가 낮아질 수 있습니다. 여러 자료를 함께 넣을 경우, 가능하면 자료의 관계와 분석 목적을 함께 입력해 주세요.
1. 무엇을 넣나 소스코드, 화면 캡처, SQL, 설계서, 업무 문서, PPT 같은 판단 근거 자료를 넣습니다.
2. 얼마나 걸리나 단일 기능·단일 화면 기준 자료는 보통 수 분 단위로 판단판 초안을 확인하는 흐름을 목표로 합니다. 자료량과 실행 환경에 따라 달라질 수 있습니다.
3. 무엇이 나오나 판단 질문, 근거, 부족한 정보, 선택지, 리스크, 실행 가능 여부를 정리한 판단판과 문서화 산출물이 나옵니다.
4. 무엇을 할 수 있나 회의 검토, 보완 자료 요청, 실행 보류/진행 판단, 내부 보고, 외부 공유용 자료 작성에 활용할 수 있습니다.

가이드 구성

이 문서는 모든 화면에서 공통으로 참고하는 사용 가이드입니다. 각 화면의 `ⓘ 사용법`, `ⓘ 워크스페이스 사용법`, `ⓘ 판단판 사용법`은 해당 화면에서 바로 눌러야 할 버튼과 짧은 조작 순서만 안내합니다.

1. 공통 내용 멜로우 링크 판맥의 목적, 입력 자료, 분석 처리 흐름, 결과 해석 기준, 신뢰도와 상태값 의미를 설명합니다.
2. 화면별 사용법 프로젝트 생성 화면, 분석 워크스페이스 화면, 결과 판단판 화면에서 사용자가 어떤 순서로 확인하고 조작해야 하는지 정리합니다.

1. 멜로우 링크 판맥 개요

멜로우 링크 판맥은 컨설팅 자료, SQL, 설계서, 구현 문서, PPT 등 다양한 입력 자료를 바탕으로 사용자가 판단해야 할 문제를 구조화합니다.

이 도구는 자료를 요약하는 데서 멈추지 않고, 자료가 요구하는 판단, 확인해야 할 근거, 부족한 정보, 가능한 선택지, 실행 가능 여부를 분리하여 검토 가능한 형태로 정리하는 것을 목표로 합니다.

2. 개발 목적과 지향점

목표는 사용자가 흩어진 자료를 넣었을 때, 그 자료가 요구하는 판단과 근거, 부족한 지점, 선택지, 실행 가능 여부를 구조화하여 더 나은 판단을 하도록 돕는 것입니다.

중심 가치 답을 대신 확정하기보다 어떤 판단이 필요한지 드러냅니다.
근거 구분 예쁜 요약보다 근거와 추정을 분리합니다.
결정 지원 무엇을 결정해야 하고 무엇이 아직 부족한지 보여줍니다.
후속 작업 검토자가 실행 가능 여부를 판단할 수 있는 판단판과 문서화 결과를 제공합니다.

현재 또는 향후 지원 대상은 다음과 같습니다. 입력 자료가 명확할수록 분석 결과의 신뢰도가 높아집니다.

5. 결과 화면 읽는 방법

판단판 기본 구조

항목 읽는 기준
상황 / 목적왜 이 판단을 하고 있는지 확인합니다.
문제 정의지금 무엇이 막혀 있는지 확인합니다.
판단 질문그래서 무엇을 결정해야 하는지 확인합니다.
선택지 비교가능한 대안과 차이를 확인합니다.
판단 기준비용, 리스크, 속도, 유지보수 등 판단 기준을 확인합니다.
결론권장 방향을 확인합니다.
리스크판단이 틀리거나 실행하지 않을 때의 위험과 검증 필요 항목을 확인합니다.

상태값 해석

상태 의미
실행 가능현재 근거만으로 실행 판단이 가능합니다.
조건 확인 후 실행일부 조건을 확인한 뒤 실행할 수 있습니다.
검증 후 실행핵심 근거가 부족하여 추가 검증이 필요합니다.
차단 / 실행 금지현재 자료 기준으로 실행하면 위험하거나 판단 근거가 부족합니다.

신뢰도 해석

신뢰도 의미
높음입력 자료와 판단 근거가 충분히 연결되어 있습니다.
중간주요 판단은 가능하지만 일부 근거 확인이 필요합니다.
낮음자료 부족, 목적 불명확, 입력 불일치 등으로 결과를 바로 신뢰하기 어렵습니다.

화면별 사용법

화면별 `ⓘ ... 사용법` 버튼은 짧은 조작 안내입니다. 아래 내용은 같은 흐름을 조금 더 자세히 풀어 쓴 공통 참고 설명입니다.

프로젝트 생성 화면
  1. 로그인 상태를 확인합니다.
  2. 프로젝트명, 고객사명, 분석 목표를 입력합니다.
  3. SQL, PPT, 설계서, 업무 문서 등 분석할 자료를 업로드합니다.
  4. 익명화 리뷰와 표시 안내를 확인합니다.
  5. 프로젝트를 생성한 뒤 워크스페이스 또는 결과 화면으로 이동합니다.
분석 워크스페이스 화면
  1. 프로젝트 개요와 진행 상태를 먼저 확인합니다.
  2. 분석이 완료되면 결과 보기 버튼으로 판단판을 엽니다.
  3. 추가 자료가 있으면 파일을 선택하고 추가 자료 업로드를 실행합니다.
  4. 현재 자산으로 다시 분석해야 할 때는 재분석을 실행합니다.
  5. 진행 이력과 자산 목록으로 어떤 근거가 사용됐는지 확인합니다.
결과 판단판 화면
  1. 결정 요약에서 최종 판단과 실행 상태를 확인합니다.
  2. 상황, 문제, 판단 질문, 선택지, 기준, 결론, 리스크 순서로 읽습니다.
  3. 검증 필요, 차단, 신뢰도 낮음 상태가 있으면 즉시 실행하지 않고 근거를 보강합니다.
  4. 내부 검토 화면과 외부 공유 화면을 구분해 확인합니다.
  5. 필요하면 검토용 Markdown, DOCX, PPTX, PDF로 내보냅니다.

6. 유형별 활용 예시

SQL/프로시저 분석 SQL, 프로시저, 트리거를 입력하면 현재 로직의 역할, 처리 흐름, 테이블 관계, 잠재 리스크, 개선 가능성을 검토하는 데 활용할 수 있습니다.
PPT 컨설팅 자료 분석 PPT 자료를 입력하면 목차, 전개 흐름, 핵심 메시지, 근거 부족 영역, 보완이 필요한 장표를 확인하는 데 활용할 수 있습니다.
설계/구현 자료 분석 설계서나 구현 자료를 입력하면 업무 흐름, 화면 구조, 테이블 구조, 구현 단계에서 필요한 확인 항목을 정리하는 데 활용할 수 있습니다.
복합 자료 묶음 분석 여러 자료를 함께 입력하면 자료 간 관계를 바탕으로 현재 상태, 문제, 개선 방향을 종합 검토할 수 있습니다. 단, 자료 간 관계가 불명확하면 결과 신뢰도가 낮아질 수 있습니다.

7. 현재 구현 수준

현재 구현 수준은 과장하지 않고 다음 상태로 구분합니다.

영역 상태 설명
기초 파이프라인 안정화 구현됨 입력 분리, 익명화, 근거 기록, 진단 리포트의 기본 흐름을 제공합니다.
구조 분석 엔진 부분 구현됨 문서, 코드성 자료, DB 관련 자료, 메모성 입력을 구분하여 분석하는 기준을 확장하고 있습니다.
전략 추천 엔진 부분 구현됨 선택지 생성, 추천 조건, 금지 조건, 판단 충돌 정리를 지원합니다.
실행 로드맵 부분 구현됨 실행 우선순위와 단계별 계획을 생성하되, 실제 변경 실행이나 배포 자동화는 현재 범위가 아닙니다.
오케스트레이션 실험 중 역할별 AI 분기, 중간 검증 루프, 실패 시 재요청, 최종 취합은 단계적으로 고도화 중입니다.
무승인 자동 실행 현재 범위 아님 분석 결과를 근거로 코드를 자동 수정하거나 배포까지 수행하는 기능은 제공하지 않습니다.

8. 한계와 검증 필요 항목

분석 워크스페이스는 입력 자료에 없는 사실을 보장하지 않습니다. 다음 경우에는 결과를 그대로 실행하지 말고 추가 검토가 필요합니다.

  • 입력 자료의 목적이 불명확한 경우
  • 자료 간 관계가 설명되지 않은 경우
  • 핵심 테이블 또는 업무 기준이 누락된 경우
  • 결과 신뢰도가 낮음으로 표시된 경우
  • 검증 필요 항목이 남아 있는 경우

9. 향후 고도화 방향

  • SQL/프로시저/트리거 분석 정확도 강화
  • PPT 컨설팅 자료의 목차, 흐름, 전개 구조 분석 강화
  • 설계/구현 자료의 업무 흐름, 테이블 관계, 화면 구조 추출 강화
  • 여러 자료를 한 번에 넣었을 때 자료 간 관계를 자동 정렬
  • 결과를 내부 검토용, 의사결정자 보고용, 외부 공유용으로 분리 출력
  • 실행 로드맵과 후속 작업 관리 기능 강화
  • 특정 컨설팅 판단 영역에서 재현성 있고 검증 가능한 분석 결과 제공
