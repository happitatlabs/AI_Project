분석 대상
소스코드, 화면 자산, SQL, 스키마, 관련 문서를 한 프로젝트로 묶어서 읽습니다.
분석 과정
입력 정리 -> 자산 분석 -> 업무 규칙 및 설계 초안 추출 -> 추천안, 우선순위, 실행 준비 계획 정리 순서로 진행합니다.
회의에서 결정할 것
어떤 방향으로 현대화할지, 무엇부터 바꿀지, 추가 자료가 필요한지, 다음 검토를 진행할지를 결정합니다.
