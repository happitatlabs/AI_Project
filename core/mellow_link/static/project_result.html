펼치기
분석 목표
레거시 기능 또는 화면 1개에 대해 무엇을 유지하고 무엇을 바꿔야 하는지 판단합니다.
읽는 순서
결정 요약 -> 판단 근거 -> 실행 조치 -> 유지 계약 -> 설계 선택지 -> 실행 계획 -> 범위 및 한계 순서로 보면 승인 판단이 빨라집니다.
회의에서 결정할 것
어떤 방향을 채택할지, 무엇부터 바꿀지, 추가 자료가 필요한지, 다음 단계 검토를 진행할지를 결정합니다.
근거 및 추적
핵심 업무 규칙 카드의 근거 자산, 부록의 provenance, 입력 자산 목록으로 판단 근거를 추적할 수 있습니다.
