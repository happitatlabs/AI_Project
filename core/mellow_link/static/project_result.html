읽는 방법

읽는 순서
핵심 결론 -> 추천안 -> 분리 우선순위 -> 설계 선택지 비교 -> 실행 계획 순서로 확인하면 됩니다.
회의에서 결정할 것
어떤 방향을 채택할지, 무엇부터 바꿀지, 추가 자료가 필요한지, 다음 단계 검토를 진행할지를 결정합니다.
근거 및 추적
핵심 업무 규칙 카드의 근거 자산, 부록의 provenance, 입력 자산 목록으로 판단 근거를 추적할 수 있습니다.
