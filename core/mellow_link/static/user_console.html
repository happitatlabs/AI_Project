Analysis Workspace

분석 워크스페이스

업로드 자산을 정리하고 무엇을 분석 중인지, 어떤 조치 제안을 만들고 있는지, 결과 패키지에서 무엇을 결정하게 될지를 한 화면에서 확인합니다.

새 프로젝트 내 프로젝트 결과 보기
프로젝트 정보를 불러오는 중입니다.

분석 목표

무엇을 판단하나

레거시 기능 또는 화면 1개를 기준으로 유지할 것, 바꿀 것, 분리할 것을 판단할 수 있는 자료를 만듭니다.

분석 과정

어떻게 진행되나

입력 정리 -> 자산 분석 -> 업무 규칙 및 설계 초안 추출 -> 조치 제안 생성 -> 결과 패키지 요약 순서로 진행합니다.

현재 생성물

워크스페이스 역할

조치 제안은 분석 결과로부터 도출되며, 워크스페이스에서 생성되고 결과 패키지에서 요약 및 비교 형태로 정리됩니다.
