# Mellow-Link Flow Maps and Specs

## 용도

이 노트는 `mellow_link`의 흐름도, 시스템 맵, UX spec, 기술 명세 문서를 묶어 보는 참고 노트다.

## 포함하는 문서군

- 시스템 아키텍처 가이드북
- system map, technical spec
- approval gate / storage-aware / layer system flow map
- feature mindmap
- UI/console architecture spec
- 기타 구조 시각화 문서

## 어떻게 읽어야 하나

- 현재 canonical source of truth는 [[Refactoring_Support_Engine]]와 제품/엔진 관련 활성 노트다.
- 이 문서군은 그 기준을 보조하는 구조 시각화와 참고 설계 자료로 읽는 편이 맞다.
- 즉 실행 계약보다는 설명, 구조 이해, 커뮤니케이션 용도에 가깝다.

## 주의

- 오래된 spec이나 흐름도는 현재 코드와 100% 일치하지 않을 수 있다.
- 제품 정의가 충돌하면 제품/엔진 기준 노트를 우선한다.
