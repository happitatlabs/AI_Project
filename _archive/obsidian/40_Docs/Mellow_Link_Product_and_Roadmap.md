# Mellow-Link Product and Roadmap

## 제품 정의

현재 기준 `Mellow-Link`는 레거시 시스템을 분석하고, 현대화 방향과 실행 가능한 조치를 제안하는 AI 도구다.

## 대표 흐름

1. 새 프로젝트 생성
2. 자산 업로드
3. 익명화 전처리
4. `SafeAnalysisBundle` 생성
5. `rebuild_assistant` 분석
6. 결과 패키지 확인

## 현재 단계

- 1단계: 분석 + 결과 패키지
  - 완료
- 2단계: 조치 제안 + 비교
  - 부분 구현
- 3단계: 실행 준비
  - planned
- 4단계: 실행/검증/승인/배포
  - planned
- 5단계: 운영/로그/감사
  - planned

## 현재 제공 가치

- 진단
- 설계안
- 전환 초안
- 추천안
- 분리 우선순위
- 설계 선택지 비교
- 실행 준비 계획

`execution_plan`은 자동 실행이 아니라 실행 준비 계획으로 해석한다.

## 파일럿 계약 관점

현재 문서 기준의 목표는 `데모 가능`을 넘어서 `유료 파일럿 제안 및 수행 가능` 상태로 가는 것이다.

핵심 준비 항목:

- 재현 가능한 결과 패키지
- 프로젝트 단위 자산 영속 관리
- 보안/설치/운영 설명 가능
- 제안서와 표준 산출물 송부 가능

## 우선 작업 축

1. 분석 품질 강화
2. 조치 제안 추가
3. 비교/Diff 구조 추가
4. 실행 준비
5. 승인/배포
6. 로그/감사
