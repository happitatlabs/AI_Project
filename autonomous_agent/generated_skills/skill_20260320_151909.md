## 스킬 정의

**이름:** `file_classifier`

**설명:** 워크스페이스의 파일을 확장자별로 분류하고 요약 보고서를 생성하는 스킬. 파일 수, 총 크기, 유형별 분포를 분석하여 Markdown 형식으로 저장한다.

**트리거 키워드:** `분류`, `classify`, `파일 정리`, `요약`

**실행 단계:**
1. 워크스페이스를 재귀적으로 스캔한다
2. 확장자별로 파일을 그룹화한다
3. 각 그룹의 파일 수와 총 크기를 계산한다
4. 결과를 Markdown 보고서로 저장한다
