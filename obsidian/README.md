# Obsidian Export Notes

이 폴더는 `AI_Project`를 옵시디언에서 바로 탐색할 수 있게 정리한 요약 노트 묶음이다.

## 추천 배치

- 옵시디언 볼트가 따로 있다면 이 `obsidian/` 폴더 전체를 볼트 루트 아래 `Projects/AI_Project/` 같은 위치에 넣는다.
- 저장소 자체를 옵시디언 볼트로 쓰고 있다면 현재 위치인 `AI_Project/obsidian/`를 그대로 사용하면 된다.

## 폴더 구조

- `00_Index`
  - 진입점 노트
- `10_Areas`
  - 역할 그룹과 상위 구조 정리
- `20_Projects`
  - 실제 프로젝트/제품 단위 정리
- `30_Engines`
  - 엔진/모듈 심화 정리
- `40_Docs`
  - 제품 활성 문서 묶음과 주제별 MOC
- `50_Policies`
  - 실행, AI 보정, 출력 정책
- `60_Contracts`
  - 실행 계약과 확장 계약
- `70_Validation`
  - QA, golden sample, validation run
- `80_Catalogs`
  - 원문 파일과 옵시디언 노트 매핑 카탈로그
