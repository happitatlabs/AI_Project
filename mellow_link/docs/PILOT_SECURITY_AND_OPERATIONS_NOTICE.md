# 파일럿 운영·보안 안내

이 문서는 고객 제출/설명용 파일럿 운영·보안 브리프다.  
마케팅 문구가 아니라 현재 구현 기준의 데이터 취급, 접근, 보관/삭제 한계와 파일럿 범위를 설명한다.

## 1. 한눈에 보는 안내

- 이 파일럿은 `단일 기능 / 단일 화면 / 단일 업무 흐름` 기준의 현대화 분석 초안을 제공한다.
- 업로드 자산은 프로젝트 분석과 재분석에 사용될 수 있으며, 프로젝트 단위로 관리된다.
- 분석 실행 전에는 익명화 전처리 계층을 거쳐 safe bundle 기반 입력으로 변환된다.
- 결과는 설명 가능한 분석 초안과 설계 초안이며, 운영 배포 및 실행 성공을 보장하지 않는다.
- 자료가 누락되면 결과는 `partial` 상태의 부분 초안으로 제공될 수 있다.
- 반복 분석을 위해 추가 자료를 다시 업로드할 수 있다.

## 2. 현재 구현 기준의 데이터 저장 위치

- 저장 위치는 로컬 절대경로 하드코딩이 아니라 설정 기반 경로 구조로 설명한다.
- 현재 제품 기준 구조는 아래와 같다.
  - 애플리케이션 DB: `mellow_link/data/aventurine_v3.db`
  - 임시 업로드(staged): `mellow_link/data/temp_uploads`
  - 프로젝트 자산: `mellow_link/data/project_assets`
  - 익명화 저장 루트: `ANONYMIZATION_STORAGE_ROOT`
    - originals
    - canonical
    - structures
    - exports
    - mappings
- 위 경로는 현재 제품 구조를 설명하는 기준이며, 고객 환경의 실제 배치 절대경로를 의미하지 않는다.
- 익명화 저장소 실제 물리 경로는 설정 또는 환경변수로 분리한다.

## 3. 접근 통제와 인증 방식

- 현재 앱 접근 인증은 Bearer JWT 기반이다.
- 프로젝트와 자산 접근은 프로젝트 소유자 기준 검증을 전제로 한다.
- 프로젝트 자산 및 결과 조회도 프로젝트 소유자 기준 검증을 전제로 한다.
- 현재 구현상 일부 운영자 제어 기능은 관리자 권한 계정에 한해 허용된다.
- 세부 role 체계, 감사 체계, 전사 운영 통제 체계는 이번 파일럿 범위 밖이다.

추가 경계:

- original content, original path, mapping 정보는 일반 사용자 HTTP 응답에 포함하지 않는다.
- 익명화 `FULL` canonical 분석본은 내부 분석 기준본이며, 기본적으로 외부 다운로드 대상이 아니다.
- 외부 제공 산출은 `PARTIAL` 또는 `FULL_MASKED` 계열 export를 기준으로 한다.

## 4. 보관 기간

- 현재 구현 기준으로 프로젝트 자산은 별도 삭제 기능이 없으므로, 운영상 프로젝트 종료 시점까지 보관을 전제로 한다.
- 자동 만료 정책은 현재 구현에 포함되어 있지 않다.
- 임시 업로드와 프로젝트 자산은 분석 및 재분석 흐름을 위해 보관될 수 있다.
- 익명화 산출물 역시 같은 운영 보관 정책 아래에서 관리된다.

## 5. 삭제/정리 방식

- 자동 삭제는 미지원이다.
- 체계화된 삭제 기능은 후속 범위다.
- 현재는 파일럿 운영 절차 기준의 수동 관리 대상이다.
- 따라서 본 파일럿은 고객용 자동 보관 만료, 셀프 삭제, 감사 이력 기반 삭제 승인 절차를 제공하지 않는다.

## 6. 현재 비지원 / 한계

- 전체 시스템 자동 전환
- 자동 코드 치환
- 운영 배포 및 실행 보장
- 대규모 리팩터링 일괄 수행
- 자동 삭제 / 자동 보관 만료
- 전사 관리자 포털이나 감사 체계가 이미 완성된 것처럼 해석될 수 있는 운영 기능
- 외부 사용자에게 canonical full source나 mapping을 직접 제공하는 기능

## 7. 고객 안내 문구

- 이 파일럿은 `단일 기능 / 단일 화면` 기준의 파일럿 범위를 전제로 한다.
- 분석 정확도와 설명력은 제공 자료 범위에 영향을 받는다.
- 자료 누락 시 결과는 `partial` 상태의 초안이 될 수 있다.
- 반복 분석이 필요한 경우, 추가 자료를 업로드해 같은 프로젝트 기준으로 재분석할 수 있다.
- 본 파일럿의 결과는 의사결정 지원용 초안이며, 운영 배포/실행 보증 문서가 아니다.
- 외부 공유본이 필요한 경우에는 구조 마스킹 수준이 적용된 export를 별도로 사용한다.
